Solon is an open specification for making AI agent behavior provable instead of assumed. It defines two things: a rule grammar — every constraint an agent must follow reduces to one of five enforcement types (MUST DO, MUST NOT DO, HUMAN-IN-LOOP TRIGGER, STOP, CONTINUE-BUT-NOTIFY) — and a receipt format — a cryptographically signed, tamper-evident record of what the agent actually did, chained so any modification is detectable. Anyone can implement Solon, in any language, on any agent framework. This repo is the spec itself: the protocol, not an implementation. The reference implementation lives in core.
